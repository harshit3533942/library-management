# Library Management (Static HTML)

This project is a static HTML/CSS/JavaScript app. You can run it in VS Code with the preconfigured tasks.

## Run in VS Code (Step by Step)

1. **Open the folder**  
   - In VS Code, go to **File → Open Folder…** and select this repository folder.

2. **Start the built-in server**  
   - Open **Run and Debug** (`Ctrl+Shift+D` / `Cmd+Shift+D`)  
   - Choose **Open Library Management** from the dropdown  
   - Click **Start Debugging** (green play button)

3. **App opens automatically**  
   - VS Code starts a local server and launches:  
     `http://localhost:5500/login.html`

## Alternative (Live Server)

If you prefer the Live Server extension:

1. Install the recommended **Live Server** extension (VS Code will prompt you).
2. Right-click `login.html` → **Open with Live Server**.

---

### Troubleshooting
- Ensure **Python 3** is installed if you use the built-in server.
- If port **5500** is busy, stop the running server and try again.
